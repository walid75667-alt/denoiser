# Application artwork

MicDenoiser.png is the source artwork generated for this application.
MicDenoiser.ico contains transparent, 32-bit BMP icon frames at 16, 20, 24,
32, 40, 48, 64, 96, 128 and 256 pixels. The BMP encoding supports both the
Windows executable and NSIS icon resource compiler. WPF embeds both files;
tray loading uses the Windows small-icon size.
